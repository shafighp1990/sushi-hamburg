# Sushi HH: order-first identity

Updated 2026-09-07 following the owner's request to remove the repeated image-plus-slogan opening.

The homepage now starts with the restaurant logo, factual delivery information and the actual orderable menu. There is no promotional hero, giant lead photograph or three-line slogan. Category tabs, dish prices, ingredients links and add-to-cart actions are immediately in the first content section. A persistent desktop order summary complements the existing cart sheet. Mobile uses compact product rows and a bottom basket action. The knowledge library and all product detail routes remain available.

## Typography

- Unbounded, variable 200–900, for titles and price emphasis: https://github.com/googlefonts/unbounded
- Golos Text, variable 400–900, for descriptions, forms, navigation and reading: https://github.com/googlefonts/golos-text

Both are self-hosted WOFF2 files in `public/fonts`, downloaded from the Google Fonts source collection, with their SIL OFL licenses included. No Google Fonts request is made by visitors. Font glyph maps were checked for German umlauts, ß, Ukrainian Ґ/Є/І/Ї and Cyrillic letters. Font payload is approximately 336 KB total before transport compression. No claim is made that these fonts are exclusive to this restaurant.

## Supplied identity

The user's original 640×640 JPEG is retained byte-for-byte at `public/brand/sushi-hh-original.jpg`. The header and favicon SVGs only frame/embed those original pixels in a tighter viewport: no logo shapes, lettering or colors were redrawn or generated. The logo is used by the shared header, page metadata and default favicon. The palette uses graphite, gold and salmon red from the supplied identity. Apple touch icon uses the original image.

## Reference research

Reviewed actual navigation and ordering content from:

- Kura Sushi Japan: https://www.kurasushi.co.jp/ — menu, store/reservation and takeaway/order entry points.
- GO by Steffen Henssler ordering: https://hensslergo.simplywebshop.de/storedata/listStore — ordering begins with the store/fulfilment choice.
- Sushije: https://www.sushije.de/ — menu, collection/delivery and concrete food selections. This site also has a slogan; the research does not support claiming that all real restaurant sites avoid slogans.

The resulting layout is an original application of ordering priorities, not a copied design. Reference sites' prices, photos and operating details are not used for Sushi HH.
